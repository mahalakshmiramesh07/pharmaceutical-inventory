Pharmaceutical Inventory Management System

Project Overview

The Pharmaceutical Inventory Management System is a web-based application designed to manage pharmaceutical stock and inventory efficiently.

Technologies Used

- Python
- HTML
- CSS
- JavaScript
- Database Connectivity

Project Modules

- Inventory Management
- Database Configuration
- User Interface
- Stock Management

Project Files

- "app.py" – Main Python application
- "db_config.py" – Database configuration
- "index.html" – Web page structure
- "script.js" – JavaScript functionality
- "style.css" – Website styling

Objective

To simplify pharmaceutical inventory management and make stock-related operations easier and more organized.

Conclusion

This project provides a basic web-based solution for pharmaceutical inventory management.
